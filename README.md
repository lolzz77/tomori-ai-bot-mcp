# tomori-ai-bot-mcp

Setup

1. Go to Render, pull this git
2. `pip install -r requirements.txt`
3. Run the script by `python server.py`
4. In the console output, will have a URL, something like `https://xxx.onrender.com`
5. Go to discord where Tomori is added, run `/config`
6. Under `plugins`, go to `MCP Server`
7. Fill in like this `https://xxx.onrender.com/mcp`
8. Like, put the `mcp` behind.
9. Done.
10. Ask the AI to use the skill
11.
